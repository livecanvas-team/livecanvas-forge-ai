    What does Full Access allow?

    The new connection requests content, media, theme files, builds, debugging, cache and SEO access. Approve only a request you started, with the matching site and code. Your WordPress account must have the required capabilities. Keep a backup before allowing writes.

    Existing connections keep their permissions. To manage sessions or use a limited-scope setup, open Instructions and troubleshooting > Open manual setup and connection management in WordPress.

    The coding agent cannot see AI Bridge
    • Confirm that you opened the same project where the generated configuration was saved.
    • Trust the project when Codex asks. Untrusted projects ignore their .codex/config.toml file.
    • After approving in WordPress, reload the Forge MCP server in the agent. Restart Claude Desktop completely.
    • If an older Forge server is also listed, check its site before choosing which server to use. Do not remove other connections during setup.
    The site URL or fingerprint is wrong

    Stop without writing. Open connection management in the intended WordPress site and check the affected session. Start a new connection from that site. Preserve unrelated servers and project settings.

    Reads work but writes do not

    Ask the agent to report the scopes and error from get_connection_handoff. A previous read-only session does not gain Full Access when the plugin is updated. Create and approve a new connection if broader access is needed. Local file and build tools can require extra runtime setup; Full Access does not grant unrestricted shell execution.

    Copy, timeout or local-site problems

    On a local HTTP site, the browser may block automatic copying. Forge then opens and selects the instructions for you to copy manually.

    If a request expires, choose Start a new connection, then copy and run the new instructions. The installer waits for approval for up to ten minutes. A stopped installer can be rerun with the same instructions while that request remains valid.

    A cloud agent cannot reach a .local site on your computer. Use a local app for that site. Public sites require HTTPS; do not disable certificate verification to connect.

    Other clients and advanced setup

    Additional clients marked configuration preview have not completed the same app tests. The manual connection screen contains generic MCP configuration and the older Direct Mode or local-runtime paths. Use them only when the new installer does not cover your setup.

    This beta's updated runtime is still being tested in real apps. Previous beta results do not qualify this version on every client or operating system.
