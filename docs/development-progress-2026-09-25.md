# LiveCanvas specialist and desktop chat implementation

The approved objective is a persistent chat inside the authenticated LiveCanvas editor connected to the same Codex desktop conversation. An independent CLI job or API-key chat does not meet this requirement. A bundled local component is permitted; a separate installation wizard is not. Initial desktop qualification targets macOS. Windows remains unqualified until tested.

The implementation also covers a shared verified write contract, versioned workflows, private site/user sessions, shared site knowledge, conflict-aware changesets and Undo, live editor context, secure local transport and multi-client qualification. New pages remain drafts. Test changes on test-ai-forge.local and marketing-rocks.local must be isolated and reversible. UI and public examples use English and exclude personal projects, chat lists and credentials.

The queue contract is now `post_claim_lease_v2`. Stop cancels queued work before a worker can claim it. Running work enters `stop_requested`; only its bound worker can acknowledge `stopped`, after its in-flight Bridge tools finish. The MCP runtime checks the lease before each tool, retains the private capability internally and retries a lost Stop acknowledgement without resuming work. WordPress persists the claimed request on the MCP session. Its six mutation permission categories reject a stopped, expired or unproven worker, even if lease headers are omitted or an administrator cookie is supplied alongside the worker session. A different explicitly claimed request can establish a new binding.

This fence applies to the claimed Bridge session. Stop does not terminate arbitrary shell commands, direct database operations, other independently authorized sessions or the coding agent itself. The UI and protocol keep `external_process_stop_verified` false. An already-running mutation may finish before acknowledgement. Stop does not undo previous changes.

Per-conversation locks coordinate enqueue, claims, clear and archive. Unfinished work, including an expired worker with an unknown result, prevents clear/archive. Archived conversations reject enqueue. Clearing terminal history advances a message generation so late completion cannot put old messages back. Lifecycle checks fail closed at the unfinished index limit of 1,000 records. Lost-worker recovery and pagination remain pending.
