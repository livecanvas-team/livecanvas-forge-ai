Connect in three steps.

  1. Start in WordPress.

    Open AI Bridge → Connect, choose your coding agent and copy its generated setup.

  2. Continue in the agent.

    Paste the setup into the same project, then reload or restart the agent when asked.

  3. Approve and verify.

    Return to WordPress, approve the matching request and ask the agent to call get_connection_handoff.

Editor chat is not available in this release. Send requests from your connected coding agent.

Need help?

The agent cannot find AI Bridge

Create a new setup from WordPress → AI Bridge → Connect, then reload the agent in the same project.

The site or fingerprint is wrong

Stop without writing. Revoke the old connection in WordPress and start a new one from the correct site.

The plugin was updated

Reload the coding agent, call get_connection_handoff again, then confirm the connection is Ready.
