# Product

## Register

product

## Users

WordPress developers, LiveCanvas implementers, agencies, and technical site administrators who use coding agents to inspect, build, and maintain LiveCanvas websites. They need an explicit, repeatable connection flow that identifies the target site before any read or write operation.

## Product Purpose

LiveCanvas AI Bridge connects coding agents to WordPress and LiveCanvas through structured read, preview, apply, and rollback workflows. It should make agent setup understandable, keep every project bound to the correct WordPress site, and expose advanced tools without turning the agent into an unrestricted remote shell.

## Brand Personality

Technical, direct, and dependable. The product should feel capable without being theatrical, and protective without making routine work cumbersome.

## Anti-references

- Generic AI dashboards that hide operational state behind decorative cards.
- Setup flows that expose secrets or long configuration blocks before the user needs them.
- Interfaces that imply a connection is ready before authentication and smoke testing pass.
- Marketing-style copy, oversized headings, ornamental gradients, or unfamiliar controls in task-focused screens.

## Design Principles

- Show the next required action before implementation detail.
- Make site identity and connection state impossible to overlook.
- Prefer generated, project-scoped configuration over global configuration.
- Keep preview, apply, and rollback visibly distinct.
- Reveal technical diagnostics progressively, without hiding them when troubleshooting is necessary.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Support keyboard navigation, visible focus, reduced motion, high-contrast state labels, semantic headings, and layouts that remain usable at 200% zoom and on narrow screens.
